Quel salaire propose CSS pour ce poste ?

L'annonce d'origine n'indique pas de salaire. Notre estimation pour ce rôle et ce secteur à Bulle est de CHF 59'000 - 108'500 bruts par an — une estimation, pas un montant communiqué par CSS. Le calculateur de ce site convertit un salaire brut en net réel une fois l'impôt frontalier et les cotisations sociales appliqués.

Est-ce un poste à temps plein, et quel type de contrat propose CSS ?

Cette offre est un poste en temps plein. Le type de contrat affiché ici provient directement de l'annonce originale de l'employeur ; confirmez toujours les horaires exacts, le préavis et la durée d'essai avec CSS pendant le processus de candidature, ces détails pouvant varier même au sein de la même catégorie de contrat.

Ai-je besoin d'un permis de frontalier pour un poste dans le canton de Fribourg ?

Les résidents UE/AELE domiciliés dans la zone frontalière du pays voisin du canton de Fribourg peuvent demander un permis G ; l'employeur suisse le dépose auprès de l'office cantonal des migrations après signature du contrat. Les règles de zone frontalière et les délais varient selon le pays voisin et le canton — confirmez les détails auprès de l'office des migrations du canton de Fribourg ou avec les RH pendant la candidature.

Comment postuler à ce poste chez CSS ?
